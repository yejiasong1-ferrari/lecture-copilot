# Changelog

## 1.1.0 — 2026-09-16

- Added a complete Start, End, Summary, Save, and New Class workflow.
- Added branded app, menu bar, desktop, and HUD icons.
- Added double-Shift HUD hide/show.
- Improved Doubao Copy detection and added physical-click and accessibility fallbacks.
- Added automatic Doubao launch when Lecture Copilot starts.
- Added a prebuilt Apple Silicon release package and one-line installer.
- Reworked the README and installation manual for first-time users.

## 1.0.0 — 2026-09-08

- Initial public macOS release.
- Added Translate, Explain, Direct Answer, and Say in Class modes.
- Added screenshot-to-Doubao automation and floating HUD responses.
- Added basic class sessions and Markdown export.
