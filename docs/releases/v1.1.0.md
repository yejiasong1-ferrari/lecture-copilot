# Lecture Copilot v1.1.0

这次更新把 Lecture Copilot 从开发者工具整理成了更容易安装和使用的 Mac App。

## 主要更新

- 全新深色玻璃 HUD、品牌图标和 Dock 图标。
- 新增课堂状态：Start、End、Summary、Save 和 New。
- 课堂结束后由用户决定何时生成总结，不会自动打断当前流程。
- 双击 `Shift` 可快速隐藏或显示浮窗。
- 加强豆包 Copy 按钮定位、点击重试和剪贴板读取逻辑。
- 豆包未运行时会自动尝试启动。
- 改进 Translate 输出规则，减少提示词、推荐问题和 OCR 杂字混入答案。
- 新增面向普通用户的一行安装器和完整中文说明书。

## 推荐安装方式

在终端粘贴并运行：

```bash
curl -fsSL https://raw.githubusercontent.com/yejiasong1-ferrari/lecture-copilot/main/install-release.sh | bash
```

安装器会下载本 Release 的 Apple Silicon 安装包、校验 SHA-256、安装到 `/Applications`，并创建桌面启动入口。

## 系统要求

- macOS 14 Sonoma 或更新版本
- Apple Silicon Mac（M1/M2/M3/M4）
- 已安装并登录豆包 Mac 客户端
- 屏幕录制、辅助功能与自动化权限

Intel Mac 用户请按照仓库中的 [INSTALL.md](https://github.com/yejiasong1-ferrari/lecture-copilot/blob/main/INSTALL.md) 从源码安装。

> 当前安装包采用 ad-hoc 签名，尚未经过 Apple Developer ID 签名和公证。安装器会清除下载隔离属性；首次运行仍需按说明授予 macOS 权限。
